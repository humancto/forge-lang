# Changelog

All notable changes to the Forge VS Code extension are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.3.0] - Unreleased

### Added

- Language server client: launches `forge lsp` for diagnostics, hover, completion, go-to-definition, references, document symbols, formatting (Format Document) and signature help.
- Debugger: `forge` debug type backed by `forge dap` (breakpoints, step over/in/out, variables, stop on entry). F5 on an open `.fg` file works without a `launch.json`.
- Settings: `forge.path`, `forge.lsp.enabled`, `forge.trace.server`.
- Command: **Forge: Restart Language Server**.
- Marketplace metadata, icon and license.

## [0.2.0]

### Added

- Syntax highlighting, 24 snippets and language configuration.
